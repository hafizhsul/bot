# bot

Kumpulan bot yang dijalankan di satu server. Setiap subfolder adalah project mandiri.

| Folder | Deskripsi | Stack |
|---|---|---|
| `agent/` | Remote control OpenCode CLI via Telegram | Node.js/TypeScript |
| `bot-yt/` | Unduh MP3/MP4 dari YouTube, Facebook, TikTok, Instagram, X via Telegram | Python, yt-dlp, python-telegram-bot |
| `repo-radar/` | Bot Discord: kartu repo GitHub trending & searchable | Python |
| `repo-reviewer/` | Bot Discord: review repo GitHub dari link atau `/review <url>` | Python |

Setiap project punya `README.md` sendiri dengan setup & cara pakai.
